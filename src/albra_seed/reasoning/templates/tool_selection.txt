(if any) that should be invoked. The selection must respect the
agent's permissions and risk level. If no tool is appropriate, return
an empty list.

$tools

Permissions: $permissions
Risk budget: $risk_level

Return strict JSON:
{
  "selected": [
    {"tool": "...", "arguments": {}, "reason": "..."}
  ]
}
